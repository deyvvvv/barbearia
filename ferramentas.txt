pesca:
Eu inicio o sistema pelo PowerShell, o Java executa a aplicação, configura a conexão com o banco 
usando HikariCP e JDBC, conecta ao PostgreSQL e, após a conexão bem-sucedida, libera o menu do sistema no terminal.


PostgreSQL JDBC Driver (postgresql-42.7.6.jar) — conexão com o banco
HikariCP (hikaricp-6.2.1.jar) — pool de conexões
SLF4J API (slf4j-api-2.0.17.jar) + SLF4J Simple (slf4j-simple-2.0.17.jar) — logging


As classes DAO (src/dao/) são quem fazem todas as consultas e manipulações no banco:
Arquivo	Responsabilidade
AgendamentoDAO.java	CRUD de agendamentos
AvaliacaoDAO.java	CRUD de avaliações
BarbeiroDAO.java	CRUD de barbeiros
ClienteDAO.java	CRUD de clientes
PagamentoDAO.java	CRUD de pagamentos
ServicoDAO.java	CRUD de serviços
RelatorioDAO.java	Consultas de relatórios (JOINs, GROUP BY, etc.)
Cada DAO tem os métodos inserir(), listar(), buscarPorId(), atualizar(), deletar() — é a camada que executa o SQL direto no PostgreSQL.
